# NEXORA AI product roadmap

1. **Product workspace — complete.** Branded dashboard, welcome screen, study assistant preview, learning tool directory, conversations, planner, and document empty state. Responsive midnight and light themes, sample lesson, local attachment previews, and session-only task interactions make the learning workflow explorable. Fixtures live in `src/data/fixtures.ts`. The profile shows the proposed allowances; it does not represent enforced usage.

2. **Student accounts and private data.** Connect Netlify Identity for email/password, Google sign-in, recovery, profiles, secure sessions, and sign-out. Use Netlify Database with Drizzle for profiles, conversations, messages, tasks, and usage records. Enforce ownership on every read and write. Replace the demo identity and fixtures with real account data; save planner changes and conversation history.

3. **Reliable AI study assistance and daily allowances.** Connect server-side Netlify AI Gateway through the existing framework's server routes. Add streaming responses, cancellation, errors, retry, and conversation history. Implement atomic server-verified allowances per authenticated user and UTC day: 20 questions, 12 images, 3 PDFs, 2 audio summaries, 5 quizzes, 5 flashcard generations, and 3 document analyses. Reject over-limit operations before expensive calls, handle concurrency and retries, reconcile failed requests, and display authoritative remaining counts and reset timestamps. Disable only the exhausted operation. Never use browser state to enforce limits.

4. **Private attachments and homework recognition.** Add client-side image compression, upload progress, camera permission handling, validation on both client and server, and private Netlify Blobs storage. Bind metadata to account ownership in Netlify Database. Add safe document parsing, retention/deletion controls, image question recognition, and explanations. Enforce upload size, MIME/content validation, and PDF page limits before AI processing.

5. **Core learning tools.** Connect academic writing, multilingual translation, quizzes with answer explanations, smart notes, flashcards with spaced repetition, professional subject tutors, document analysis, and step-by-step homework assistance. Use structured outputs and allow students to save and revisit results. Add source analysis with verifiable citations and make uncertainty clear.

6. **The $2 upgrade.** Finalize whether $2 is a one-time purchase or recurring, what allowances it includes, and whether each tool has one or two introductory uses. Present those terms before checkout. Add hosted payment checkout, verified webhooks, idempotent fulfillment, subscription/refund handling where relevant, and server-verified entitlements. Do not count opening a tool as a trial use; grant usage only through validated generation operations. Keep baseline free allowances accessible. No payment is collected by the current preview.

7. **Academy, audio, and launch readiness.** Add curated recorded lectures, accessible playback, voice input, bounded audio summaries, and persistent study scheduling. Validate keyboard and screen reader flows, mobile camera behavior, password recovery, upload privacy, quota races, reset boundaries, and payments in a deployment preview before production. Measure loading performance, add operational monitoring and abuse controls, and keep expensive background processing bounded.
